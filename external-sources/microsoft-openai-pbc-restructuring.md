## Source

**The Next Chapter of the Microsoft–OpenAI Partnership** — October 28, 2025, Microsoft Corporate Blogs

**Restructuring & ownership**
- Microsoft backs OpenAI's board creating a **public benefit corporation (PBC)** and a recapitalization.
- Post-recapitalization, Microsoft's stake in **OpenAI Group PBC** is valued at roughly **$135 billion**, equating to about **27 percent** on an as-converted diluted basis (covering employees, investors, and the OpenAI Foundation).
- Before recent funding rounds, Microsoft's stake stood at **32.5 percent** of the for-profit entity.

**Continued / changed terms**
- "OpenAI remains Microsoft's frontier model partner," retaining exclusive IP rights and Azure API exclusivity until AGI.
- An **independent expert panel** will verify any AGI declaration by OpenAI.
- Microsoft's product/model IP rights now extend **through 2032**, including some post-AGI models with safety guardrails; research IP rights last until AGI verification or **through 2030**.
- OpenAI committed to purchasing an **incremental $250B of Azure services**; Microsoft loses its right of first refusal as compute provider.
- OpenAI may now serve US government national-security customers on any cloud and release qualifying open-weight models.

## Highlights

- Microsoft **~27%** of OpenAI Group PBC, ~**$135B** value (down from 32.5% via dilution); ~$13.8B invested historically.
- New structure: nonprofit **OpenAI Foundation** controls the for-profit **OpenAI Group PBC**.
- **$250B** incremental Azure commitment; partnership intertwined **through 2032**.
