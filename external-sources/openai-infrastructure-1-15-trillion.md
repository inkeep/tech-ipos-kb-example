## Source

OpenAI has committed an estimated **~$1.15 trillion** on hardware & cloud infrastructure between **2025 and 2035**, across seven major vendors:

| Vendor | Commitment | Nature |
|---|---:|---|
| Broadcom | ~$350B | Custom OpenAI-designed accelerators (10 GW) |
| Oracle | ~$300B | Cloud compute (4.5 GW, Stargate) |
| Microsoft | ~$250B | Incremental Azure services |
| Nvidia | ~$100B | GPUs / systems (10 GW) + equity |
| AMD | ~$90B | Instinct GPUs (6 GW) + warrant |
| Amazon (AWS) | ~$38B | Cloud compute |
| CoreWeave | ~$22B | GPU cloud capacity |

These are **purchase/compute commitments** spread over a decade — distinct from equity *investments into* OpenAI (e.g., Nvidia's up-to-$100B investment, Amazon's up-to-$50B). Several counterparties sit on **both** sides (sell compute to OpenAI **and** hold/receive OpenAI-linked equity), which is the "circular financing" dynamic.

## Highlights

- **~$1.15T** total compute/cloud/chip commitments, 2025–2035.
- Largest lines: **Broadcom $350B**, **Oracle $300B**, **Microsoft $250B**.
- Many vendors are simultaneously **investors and suppliers** — the core of the AI capital web.
